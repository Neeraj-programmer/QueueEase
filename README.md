# QueueEase

QueueEase is a campus queue management system for educational institutions.

## Features
- Student & Visitor tokens
- Real-time wait tracking
- Admin dashboard for staff to call next tokens

## Tech Stack
- MongoDB
- Express.js
- React.js
- Node.js

## How to run
1. Clone the repository
2. Run `npm install` in client and server folders
3. Add your `.env` variables
4. Run `npm run dev` in both folders
